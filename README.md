# Sistema de Controle de Notas e Frequência

Projeto acadêmico desenvolvido durante o segundo semestre de 2025, quando cursava o segundo período de Ciência da Computação. O objetivo foi criar um sistema para auxiliar professores no controle de notas e frequência dos alunos.

O sistema possui duas versões: uma desenvolvida em C, utilizando programação estruturada, e outra em Python, utilizando programação orientada a objetos.

## Funcionalidades

- Seleção de disciplinas.
- Cadastro de alunos nas turmas A e B.
- Registro de notas e frequência.
- Cálculo automático da média dos alunos.
- Cálculo do percentual de frequência.
- Listagem dos alunos cadastrados.
- Geração de relatórios por turma.
- Cálculo da média geral das turmas.
- Comparação do desempenho entre as turmas A e B.

## Tecnologias e conceitos utilizados

**C**
- Estruturas (struct).
- Funções.
- Vetores.
- Estruturas condicionais e de repetição.
- Manipulação de strings.

**Python**
- Programação orientada a objetos.
- Classes, objetos e métodos.
- Listas e dicionários.
- Estruturas condicionais e de repetição.
- Importação e organização de módulos.
